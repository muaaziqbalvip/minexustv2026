Live Movie/Series Data (TMDB API)

MINEXUS TV pulls live trending movies, series, and search results from TMDB (The Movie Database). Get a free personal API key at themoviedb.org/settings/api, paste it below, and the app will automatically switch to always-live TMDB data — no code editing needed. Without a key, the app still works using the free Cinemeta catalog as a fallback.

AI-Powered Search (Groq)

When a visitor's search doesn't match a title directly — e.g. "best world movie ever", "wo film jisme banda time travel karta he", or a misspelled title — the app asks Groq's AI to figure out the actual movie/show titles being described, then looks each one up on TMDB for real, playable results. Get a free key at console.groq.com/keys. Without a key, search still works normally (direct title matching only) — this is a pure enhancement.

Default: openai/gpt-oss-120b (fast + high daily limits on Groq's free tier). Change only if Groq deprecates/renames it — check console.groq.com/docs/models.

Default Streaming Server

MINEXUS TV includes 25+ built-in embed servers, plus any custom ones you add below. Pick whichever is currently fastest/most reliable and every visitor's player will open on it by default. Viewers can still manually switch servers per title, and the player auto-suggests "Try Next Server" if the default one is slow.

Add / Manage Custom Servers

Found a new working embed provider? Add it here — it syncs live to every visitor's server list, no code or redeploy needed. Use {id} for the ID (pick which kind below), and for TV shows also {s} (season) and {e} (episode) in the URL pattern. Use the ↑ / ↓ buttons in the list to control the order servers are tried in (top = tried first).

Ad Slots

Paste embed code from a trusted, verified ad network (Google AdSense, or a CPM network with a real account you control) into any slot below — it syncs live to every visitor, no redeploy needed. Leave a slot empty to hide it completely; nothing shows until you add code.

⚠️ Safety note: only use code from networks you've personally signed up with and verified. Random ad-tag snippets from unfamiliar sites are a common way malware and deceptive redirects get distributed — several were caught and removed from this app for exactly that reason. When in doubt, Google AdSense is the safest and most reliable option for a site like this.
